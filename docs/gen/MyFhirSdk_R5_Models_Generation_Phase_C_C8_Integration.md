# Phase C8 generated model integration

## Ownership after the atomic switch

- `Generated/R5/Types` owns all R5 specialization datatypes and datatype components.
- `Generated/R5/Resources` owns all concrete Resources and Resource-owned Backbones.
- `Generated/R5/ModelMetadata` owns R5 factories, datatype/open-type metadata, and validation entries.
- `core` retains the C0-approved external bootstrap declarations.
- `Types/SimpleQuantity.cs` remains handwritten because `SimpleQuantity` is an excluded constraint profile rather than a specialization generated by Phase C.
- `Generated/R5/Primitives` remains owned by Phase B.

C8 used project exclusions to perform the atomic switch. C9 subsequently removed the replaced
handwritten `Types`, `Resources`, metadata entry files, and those temporary exclusions.
`MyFhirSdk.csproj` now includes generated artifacts and the retained handwritten
`Types/SimpleQuantity.cs` through the default compile glob. `R5ModelMetadataProvider` composes
`GeneratedR5ModelMetadata` and `GeneratedR5ValidationRules` directly.

## Regeneration and drift check

Generate into a staging root because the transactional writer intentionally rejects the repository root as an output target:

```powershell
dotnet run --project CodeGen/MyFhirSdk.CodeGen.csproj -- `
  --mode model `
  --input Tests/CodeGen/Fixtures/FhirPackages/R5/hl7.fhir.r5.core-5.0.0.tgz `
  --output <staging-root> `
  --fhir-version 5.0.0 `
  --package-id hl7.fhir.r5.core `
  --package-version 5.0.0
```

Copy `<staging-root>/Generated/R5/{Types,Resources,ModelMetadata}` and the model manifest into `Generated/R5`. Then run:

```powershell
dotnet test Tests/CodeGen/MyFhirSdk.CodeGen.Tests.csproj --no-restore --filter FullyQualifiedName~CommittedModelGenerationTests
dotnet build MyFhirSdk.sln --no-restore
dotnet test MyFhirSdk.sln --no-build --no-restore
git diff --check
```

`CommittedModelGenerationTests` rebuilds the official full batch in memory and compares every generated model artifact and the manifest with the committed files.

The production CLI supports only explicit `--mode primitive` and `--mode model`. The former MVP
`datatype-preview` mode and its implicit no-mode fallback were removed in C9.

## Rollback

Revert the C8 change set as a unit: generated model artifacts, project compile exclusions, generated provider composition, API snapshot, and integration tests. Do not restore handwritten compile ownership while generated declarations remain compiled, because that creates duplicate public types and metadata owners.
